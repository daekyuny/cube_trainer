## 다음 확인

1. 사용자가 직접 돌려 보며 그림의 각도, 큐브와 원 그래프의 크기·간격, 모바일에서 원 그래프의 가독성을 확인한다. 더 이상 쓰지 않는 뒤집힌 투영(`reverse`)은 정리 여부를 정한다.
2. 실제 iOS·Android에서 작은 화면, 가로 화면, 스크롤 중 큐브 표시, 터치감과 성능을 확인한다.
3. 모바일 역회전 선택 방식과 기본 애니메이션 속도를 조정한다. 실기기에서 드래그 감도(손가락 이동량 대비 회전각)·축 고정 거리·스크롤과의 충돌을 확인한다.
4. 고정 배치 다섯 유형의 Y층 페어링을 연습한 뒤, 페어 정렬·자기 슬롯 삽입을 다음 단계로 추가한다. 기존 세 슬롯 보존은 모든 페어링 수순의 필수 조건으로 유지한다.
5. 단계별 연습에 출제 기록·약한 케이스 반복, 연속 단계(OLL→PLL 이어 풀기) 옵션을 검토한다.
6. 다른 색 페어·네 페어 연속 연습·임의 배치의 힌트·로컬 저장 중 다음 목표를 정한다.

자동 풀이, 임의 각도 자유 시점 드래그, 타이머, 계정은 이번 작업 범위에 없다.
