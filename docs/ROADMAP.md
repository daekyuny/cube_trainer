## 다음 확인

1. 사용자가 직접 돌려 보며 그림의 각도, 두 큐브의 크기와 간격을 확인한다.
2. 실제 iOS·Android에서 작은 화면, 가로 화면, 스크롤 중 큐브 표시, 터치감과 성능을 확인한다.
3. 모바일 역회전 선택 방식과 기본 애니메이션 속도를 조정한다.
4. F2L 다섯 유형의 대표 배치를 실제로 연습하며 설명·수순·단계 경계를 조정한다. 초보 층별 풀이와 십자가 강좌는 건너뛴다.
5. 다른 색 페어·네 페어 연속 연습·임의 배치의 힌트·로컬 저장 중 다음 목표를 정한다.

자동 풀이, 중간층 회전, 임의 시점 드래그, 타이머, 계정은 이번 작업 범위에 없다.
