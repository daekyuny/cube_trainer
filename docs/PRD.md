# Cube Trainer — PRD v0.2

상태: 첫 조작 프로토타입 · v0.1의 임시 색상 방향과 자유 시점 제안을 사용자 피드백으로 대체했다.

## 제품 목표

실제 회전 규칙에 맞는 3×3 큐브를 데스크톱·모바일에서 직접 돌리며 연습한다. 이번 단계의 목표는 여섯 면을 구별하고, 두 그림에서 동일한 회전을 확인하며, 네 시작 상태에서 연습하는 것이다.

## 표시 규칙 — 확정

- 항상 동일한 큐브를 두 시점으로 함께 표시한다. 하나는 기준 그림, 하나는 뒤집힌 그림이다.
- 기본 방향은 U 노랑, D 흰색, F 빨강, R 초록, B 주황, L 파랑이다.
- 큰 그림은 F/R/U를 보여 준다. 앞면이 옆면보다 넓게 보여야 한다.
- 작은 그림은 B/L/D를 보여 준다. 화면 위쪽에 보이는 흰색 면은 원본 기준 D이며, 주황 B가 앞, 파랑 L이 왼쪽에 보인다.
- 작은 그림은 큰 그림보다 작게 표시한다. 그림의 센터에 F/R/U 또는 B/L/D를 붙여 방향을 알 수 있게 한다.
- 모바일에서는 조작 패널로 스크롤해도 두 그림이 붙어 다니도록 표시한다.
- 두 그림의 상태·애니메이션은 같은 논리 상태에서 계산한다. 사진 파일을 런타임에서 사용하지 않는다.

## 조작 규칙 — 확정

| 입력                  | 동작                                   |
| --------------------- | -------------------------------------- |
| f / r / u / d / l / b | 그 면의 밖에서 바라본 시계 방향 90°    |
| Shift + 문자 키       | 그 면의 반시계 방향 90°                |
| ← / →                 | 큐브 전체를 수평으로 90° 회전          |
| 모바일 십자 버튼      | 중앙 F, 왼쪽 L, 위 U, 오른쪽 R, 아래 D |
| 작은 B 버튼           | U와 R 사이에 배치                      |
| 모바일 돌림 아이콘    | 전체 큐브를 좌·우로 90° 회전           |

모바일의 역회전은 시계/반시계 방향 선택 버튼으로 제공한다. 이 선택은 화면 버튼에만 적용하며, 키보드는 항상 Shift 여부로 방향을 결정한다.

전체 수평 회전은 실제 큐브를 손으로 돌리는 것처럼 앞·옆·뒤의 기준을 바꾼다. 왼쪽 회전 후에는 기존 오른쪽 면이 F가 되고, 이후 F 입력은 새 앞면을 돌린다. 위·아래 센터는 계속 노랑·흰색이다. 면 회전으로 가장자리·꼭짓점 스티커가 다른 면으로 이동하는 것은 정상이다.

중간층 회전, 큐브 전체를 세로로 뒤집는 조작, 임의 시점 드래그는 이번 범위에 없다. 두 번째 그림의 뒤집힘은 관찰 시점이며 큐브 상태를 따로 변경하지 않는다.

## 시작 상태 — 확정

| 프리셋      | 보장할 상태                                   | 이번 생성 방식                                                    |
| ----------- | --------------------------------------------- | ----------------------------------------------------------------- |
| 맞춘 큐브   | 여섯 면 완성, 기본 방향                       | 완료 상태 생성                                                    |
| 랜덤 섞기   | 실제로 도달 가능한 섞인 큐브                  | 같은 면을 연속 선택하지 않는 25수; 대회용 무작위 상태 분포는 아님 |
| 흰색 십자가 | D의 흰색 엣지 네 개와 각 옆면 센터 정렬       | 십자가를 보존하는 회전으로 나머지 조각을 섞음                     |
| 1·2층 완성  | 흰색 아래 기준 하단 두 층 완성, 상단은 미완성 | U 회전과 아래 두 층을 보존하는 수순 적용                          |

프리셋을 누르면 이전 수순과 대기 입력을 비우고 기본 방향으로 새로 시작한다. 버튼 아래에 이 동작을 안내한다. 시작 상태를 만든 수순은 도움말에서 확인할 수 있다. 랜덤 프리셋에는 불가능한 스티커 배열을 사용하지 않는다.

## 보조 기능 — 이번 구현

- 모든 면 회전과 전체 수평 회전을 한 입력 큐로 처리한다. 큐는 최대 20수이며 초과 입력은 안내하고 거절한다.
- 보통/느린 회전, 모션 감소 환경에서는 즉시 결과 표시.
- 실행된 수순 표시와 한 수 되돌리기. 전체 회전도 이력에 기록하되 면 회전 횟수에는 포함하지 않는다.
- 되돌리기는 회전 대기 중 비활성화하며, 프리셋을 바꾸면 이전 이력은 지운다.
- 현재 상태가 전체 완성, 1·2층 완성, 흰색 십자가 완성인지 표시한다.
- 키보드 반복 입력, 조합 입력, Ctrl/Alt/Meta 단축키, 입력 필드 타이핑은 회전으로 처리하지 않는다.

## 수용 기준

1. 기본 화면의 F/R/U와 B/L/D 색상·위치가 확정 규칙과 일치한다. 앞면이 옆면보다 크고, 두 번째 큐브가 더 작다.
2. 각 면의 4회 회전, 회전+역회전, 수순+역수순이 원상복구된다. 알려진 엣지 이동으로 시계 방향을 독립적으로 검증한다.
3. 전체 수평 회전을 4회 하면 원상복구되며 U/D 센터는 유지된다. 회전 후 입력은 새 기준 면에 적용된다.
4. 어떤 프리셋도 합법적인 수순으로 생성·복원할 수 있다. 흰색 십자가는 옆면까지 맞고, 1·2층 상태는 아래 두 층이 완성되어 있다.
5. 두 그림의 층 회전이 함께 애니메이션되고, 연속 입력은 입력 순서대로 적용된다.
6. 회전 도중 프리셋을 바꾸면 이전 애니메이션·대기 입력이 새 상태를 덮어쓰지 않는다.
7. 320/390/768/1440px에서 가로 넘침이 없고, 조작 중 두 큐브가 보인다. 작은 B도 최소 44px 터치 영역을 가진다.
8. 타입·린트·포맷·엔진 테스트·브라우저 테스트·빌드가 통과한다. 실제 iOS/Android 터치감과 프레임 성능은 실기기에서 후속 확인한다.
