# Lessons

- 2026-10-16 · 드래그 조작: "손가락 방향과 가장 비슷한 순간 접선"으로 축을 고르고 직선 비율로 각도를 계산했더니, 사용자는 "큐브 모양대로 움직이지 않는다"고 느꼈다. 직접 조작 UI는 화면 수학이 아니라 실물 조작 감각이 기준이다. 잡은 면의 격자 방향으로 축을 정하고, 잡은 점이 실제 경로(원호)를 따라 손가락 아래에 있도록 할 것. 또 기존 SPEC 제약(중간층·세로 회전 제외)을 이유로 드래그 범위를 좁히기 전에, 사용자가 기대하는 조작 범위를 먼저 확인할 것.
- 2026-10-27 · 사진 입력: 꼭짓점 사진 두 장 + 육각형 틀 맞추기로 색을 읽게 했더니 실제 휴대폰에서는 오류가 많아 쓰기 어려웠다. 앱 그림을 캡처한 합성 사진 테스트는 원근·그림자·반사·작은 화면에서의 끌기 정밀도를 재현하지 못한다. 실물 입력 기능은 "가장 적은 장 수"보다 "실제 촬영 조건에서 가장 견고한 방식"(면마다 정면, 화면 안내 틀, 즉시 미리보기)을 기준으로 설계하고, 합성 테스트 통과를 사용 가능성의 근거로 보고하지 말 것. 실기기 확인 전에 사용자에게 시험 포인트를 구체적으로 요청할 것.
