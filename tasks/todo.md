# 뒤집힌 큐브 → '수학적' 원 그래프 표시로 교체

결정(사용자 승인): 뒤집힌 그림 완전 교체 · 회전 시 점이 원을 따라 미끄러짐, 도는 원은 굵게·강조 · 점 위치는 화면 면(U·F·R…) 고정, 색만 이동 · 조작은 왼쪽 큐브에서만 · 움직임 기호 표시.

기하: 보이는 면 U·F·R 중심이 정삼각형(안쪽), 각 축의 고리 세 개는 그 축의 보이는 면 중심을 공유하는 동심원. 보이지 않는 B·L·D는 반대편 반사점(바깥쪽). 스티커 = 두 축 원의 교점. 고리 스티커는 원을 따라 각도 보간, 도는 면은 격자 좌표를 회전해 같은 교점 함수로 그림.

- [x] 순수 모듈 `src/features/simulator/circleMap.ts`: 원 9개, 스티커 2D 위치, 회전 중 위치, 활성 원·방향
- [x] `CircleView.tsx`: 원·점·강조·방향 화살표·움직임 기호 SVG
- [x] App: 두 번째 그림 교체, 드래그는 왼쪽 큐브 figure에서만, 안내 문구
- [x] 테스트: 단위(원 위 위치, 회전 전후 연속성, 모든 수 종류), 브라우저(표시·강조·기호·드래그 무시·반응형), 기존 cube-back 테스트 갱신
- [x] 문서: SPEC(표시 규칙·수용 기준), ARCHITECTURE, README 필요 시, ROADMAP
- [x] 검증: check / test / build / test:e2e / 시각 확인

## 결과 (원 그래프)

- 단위 70/70, 브라우저 56/56 통과 · check · build 통과 · 1440/390px 정지·회전 중(R, D′, x, U′)·F2L 화면 확인
- 각 축 원은 보이는 면(R·U·F) 중심을 공유하는 동심원이며, 숨은 면 사이 180° 빈 호를 지나는 점은 같은 시간에 더 멀리 이동함
- F2L 강조: 큐브는 색 문자, 원 그래프는 대상 점 굵은 테두리·나머지 흐리게
- 남은 것: 모바일 실기기 가독성, 쓰지 않는 `reverse` 투영 정리 여부(ROADMAP)
