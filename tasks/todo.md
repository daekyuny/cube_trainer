# 2-Look OLL · PLL을 해피 큐빙 영상 방식으로 개편

출처: 해피 큐빙 「(2024 ver) 2-Look OLL 강의」(youtu.be/K_vbxkmVZg4), 「2-Look PLL 강의」(youtu.be/FhgoXSbQ8yk) 자막·설명.
결정: 영상 공식 그대로 · 반복 동작은 괄호 묶음(트위스트 R U R′ U′, 슬레지해머 R′ F R F′) · f(앞 두 줄)·x(전체)·M(가운데 줄) 사용 · x로 시작한 공식은 x′로 되돌려 다음 단계가 노랑 위에서 시작.

- [x] 엔진: 넓은 회전 f r u d l b(바깥 면 + 가운데 층), 표기·애니메이션 공통
- [x] 안내: 괄호 묶음 파싱(묶음·트리거 이름), x/y/z 소문자 파싱, 정규화 체크포인트 비교, 체크포인트 기준 화면 변환(중간층·전체 회전 포함)
- [x] 케이스: 영상 공식으로 교체, 인식 문구를 실제 시작 배치와 대조
- [x] UI: 공식 묶음 괄호·이름 표시, 넓은 회전 버튼, 회전 제외 수 표시
- [x] 테스트: 엔진(넓은 회전), 케이스(인식·완료·연결), 세션(M/x 포함 시연·시점 회전), 브라우저
- [x] 문서: SPEC(공식 표·제약·수용 기준), ARCHITECTURE, README, ROADMAP
- [x] 검증: check / test / build / test:e2e / 시각 확인
